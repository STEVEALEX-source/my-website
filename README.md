# riz's portfolio

look, i got tired of portfolios that look like every other portfolio. so i made this thing. it's got floating 3D cubes, chaotic cats doing backflips, a fake terminal that pretends to delete your computer (it doesn't, relax), and way too many box shadows.

it's a portfolio. but make it weird.

## what's in here

- a hero section that tilts when you move your mouse, because why not
- 3D voxel cubes floating around in the background reacting to your cursor
- three pixel cats having an existential crisis somewhere on screen
- a fake terminal easter egg that scares people into thinking they broke their machine
- a projects page that pulls straight from my github (lazy? no, efficient)
- a custom cursor because the default one wasn't dramatic enough
- a perspective grid floor because i watched one too many synthwave videos

## tech stack

- react (obviously)
- vite (because waiting for webpack is a crime)
- pure css for the 3D stuff (no three.js, no libraries, just suffering)
- github api for the projects section

## how to run it

clone it:

```bash
git clone https://github.com/STEVEALEX-source/my-website.git
cd my-website
```

install the things:

```bash
npm install
```

run it:

```bash
npm run dev
```

open `http://localhost:5173` and pretend you're impressed.

## how to build it for the real world

```bash
npm run build
```

this spits out a `dist` folder. throw that on vercel, netlify, github pages, whatever. they're all free. i'm not your dad.
